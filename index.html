Suelta aquí el CSV del "Branch Collection Report"

o usa el botón "Subir informe CSV" arriba. Se lee en tu navegador, se detectan las sucursales del archivo y luego te pido la comisión de cada una antes de armar el reporte.

Cómo funciona: el archivo se procesa completo en tu navegador — ninguna fila viaja a un servidor. Sirve para cualquier reporte con la misma cabecera (Usuario, Nombre de Sucursal, Tipo, Monto Neto, Transacciones, Fecha Creado…): el cálculo se rehace automáticamente para el periodo que cargues, agrupando por sucursal, usuario y forma de pago (Efectivo, GetNet, Tarjeta, Transferencia), y separando ingresos de gastos según la columna Tipo. Filas de subtotal o encabezado repetidas dentro del propio CSV se descartan de forma automática. Antes de armar el reporte final se pide el % de comisión de cada sucursal — se guarda en este navegador para el próximo informe y siempre puedes reabrirla con "editar comisiones". El botón "Descargar Excel" exporta exactamente lo que ves en pantalla (resumen o detalle diario según la pestaña activa).
